# Panel WWW — plan wdrożenia

> Wykonanie: inline w tej samej sesji (superpowers:executing-plans), kroki `- [ ]`.

**Cel:** strona na telefon do włączania/wyłączania świateł (zakładki Oświetlenie / PV / Ogrzewanie).

**Architektura:** osobna usługa `web.service` z serwerem `http.server` (stdlib) w `scripts/web_panel.py`; Modbus przez `read_registers`/`ModbusError` z `lights_v2_`; statyczna strona w `scripts/web/`.

**Technologie:** Python 3.7 stdlib + `pyModbusTCP 0.2.0`; HTML/CSS/JS bez bibliotek.

**Spec:** `docs/superpowers/specs/2026-09-18-panel-www-design.md`

## Ograniczenia globalne

- Python 3.7: bez `list[...]` w adnotacjach i bez `:=` (3.8+).
- Brak nowych zależności na Pi.
- `lights_v2_.py` bez zmian.
- Port 80, `User=pi`, `AmbientCapabilities=CAP_NET_BIND_SERVICE`.
- Teksty na stronie po polsku.
